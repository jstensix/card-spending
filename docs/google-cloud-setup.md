# Google Cloud 설정 (구글 드라이브 백업용)

앱의 '구글 계정 연결'이 동작하려면 Google Cloud에서 **처음 한 번** 아래 설정을 해야 해요. 15분쯤 걸려요.
앱은 드라이브의 **앱 전용 숨김 폴더**(`drive.appdata`)만 쓰고, 내 드라이브의 다른 파일은 볼 수 없어요.

## 0. 내 PC의 키 지문(SHA-1) 확인

저장소 폴더에서 실행:

```bash
./gradlew :app:signingReport
```

출력에서 `Variant: debug` 아래의 `SHA1: AA:BB:...` 값을 복사해 둬요.

## 1. 프로젝트 만들기

1. https://console.cloud.google.com 접속
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 예: `card-spending` → 만들기

## 2. Google Drive API 켜기

1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Drive API` 검색 → **사용**

## 3. OAuth 동의 화면 (Google 인증 플랫폼)

1. **API 및 서비스 → OAuth 동의 화면**(또는 **Google 인증 플랫폼**) → 시작하기
2. 앱 이름(예: 카드 실적), 사용자 지원 이메일 입력
3. 대상: **외부**
4. 연락처 이메일 입력 → 완료
5. **데이터 액세스**(범위) → 범위 추가:
   - `https://www.googleapis.com/auth/drive.appdata`
   - `https://www.googleapis.com/auth/userinfo.email`
6. **대상** 메뉴 → **앱 게시**(프로덕션으로 푸시)

> **중요: 반드시 '프로덕션'으로 게시하세요.** '테스트' 상태로 두면 **7일마다 권한이 만료**돼서 백업이 멈추고 앱에 "구글 계정을 다시 연결해야 해요"가 떠요.
> 이 앱은 민감하지 않은 범위만 쓰기 때문에 게시할 때 구글 심사가 필요 없어요.

## 4. Android OAuth 클라이언트 만들기

1. **클라이언트**(또는 **사용자 인증 정보**) → **클라이언트 만들기**
2. 애플리케이션 유형: **Android**
3. 패키지 이름: `com.jstensix.cardspending`
4. SHA-1 인증서 지문: 0단계에서 복사한 값
5. 만들기

설정이 반영되기까지 몇 분 걸릴 수 있어요. 그다음 앱의 **설정 → 구글 계정 연결**을 눌러요.

## PC를 바꾸거나 Android Studio를 다시 설치했을 때

디버그 키가 바뀌어서 새 PC에서 빌드한 앱은 연결이 안 돼요. 0단계로 새 SHA-1을 확인하고, **4단계를 반복해 Android 클라이언트를 하나 더** 만들면 돼요(기존 것은 그대로 둬도 돼요).

서명 키가 바뀌면 폰에 설치된 기존 앱 위에 덮어 설치가 안 될 수 있어요. 그때는 앱을 지우고 새로 설치한 뒤, 같은 구글 계정을 연결하면 **드라이브의 최신 백업으로 복원**할 수 있어요.

# 실기기 검증 체크리스트

에뮬레이터에서 확인하지 못하는 부분(실제 카카오톡·하나카드 앱 알림, 구글 드라이브)을 실제 폰에서 확인해요.
결과 칸에 `통과` / `실패: 내용`을 적어 주세요. 실패하거나 '읽지 못한 카드 알림'에 쌓인 원문은 그대로 전달해 주세요(새 파서를 추가할 때 써요).

## 에뮬레이터에서 이미 확인한 것 (2026-11-18)

- 메인 화면, 카드 등록·수정, 미인정 항목 체크, 결제 직접 추가, 카드 결제 내역
- 알림 리스너 전체 흐름(`adb shell cmd notification post`로 만든 알림):
  - 같은 하나카드 알림 2개 → 9,900원 **1건**만 집계
  - 형식을 모르는 '하나카드' 알림 → 인식 실패 1건
  - 개인 대화 알림 → 무시
- 설정 화면, 구글 연결 취소 시 안내 문구, 메인의 백업 미연결 경고

## 실기기 체크리스트

| # | 확인할 것 | 결과 |
|---|---|---|
| 1 | Android Studio로 폰에 설치 → 앱 실행 | |
| 2 | 메인 경고 배너 → 권한 안내 → 알림 접근 허용 → 돌아오면 '켜짐' | |
| 3 | 배터리 최적화 제외 요청 → '켜짐' | |
| 4 | 카드 2장 등록(롯데·하나, 실제 끝 4자리), 카드별 미인정 항목 체크 | |
| 5 | **실제 롯데카드 결제 1건** → 메인 금액 반영, 카드 내역에서 항목을 눌러 원문 확인 (카카오톡 알림 구조 검증, 스펙 9장) | |
| 6 | **실제 하나카드 결제 1건** → 반영. 앱 푸시와 카카오톡이 둘 다 왔다면 **1건만** 집계 | |
| 7 | '읽지 못한 카드 알림'에 쌓인 것이 있으면 원문 전달 | |
| 8 | Google Cloud 설정(`docs/google-cloud-setup.md`) 후 설정 → 구글 계정 연결 → '지금 백업' → 마지막 백업 시각 표시 | |
| 9 | 앱 삭제 후 재설치 → **카드를 먼저 1장 등록** → 같은 계정 연결 → "드라이브에 백업이 있어요" 창에서 '드라이브 백업으로 복원' → 원래 카드·결제 복구 (새로 등록한 카드는 사라짐) | |
| 10 | 9번 상태에서 설정 → '연결 해제' → 다시 연결 → 이번엔 '취소' → 연결 안 됨, 드라이브 백업 그대로 | |

## 알아둘 점

- 승인 취소 알림, 하나카드 카카오톡 알림, 해외 결제 알림은 아직 실제 형식을 몰라요. 처음 오면 '읽지 못한 카드 알림'에 쌓이고, '결제로 등록'/'취소로 등록'으로 직접 반영할 수 있어요. 원문을 전달해 주시면 파서를 추가하고, 앱을 업데이트하면 쌓여 있던 알림이 자동으로 다시 읽혀요.

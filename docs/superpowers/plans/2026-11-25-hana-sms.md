# 하나카드 문자 자동 등록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 하나카드 승인 문자를 결제로 자동 등록하고(다른 경로와 중복 없이), 자동 등록 결제에 `자동(SMS)`/`자동(PUSH)`를 표시한다.

**Architecture:** `parsing/HanaSmsParser`가 문자 형식을 읽고 `CardNotificationParser`가 기존 파서 다음에 부른다. 패키지로 경로를 정하는 `channelOf`를 `model/Channel.kt`에 두고, Ingestor는 저장 전에 '다른 경로·같은 날' 중복을, `txMeta`는 라벨을 이 함수로 판단한다. `PARSER_VERSION` 2→3.

**Tech Stack:** Kotlin, Room, Robolectric 단위 테스트.

**Spec:** `docs/superpowers/specs/2026-11-25-hana-sms-design.md`

## Global Constraints

- 문자 결제 시각: 날짜는 문자의 MM/DD, 시·분은 받은 시각(`NotificationMessage.postedAt`), 연도는 `inferApprovedAt`.
- 중복: 같은 issuer·mask·amount·kind·날짜의 NOTIFICATION 행이 **다른 채널**이면 DUPLICATE. 같은 채널은 기존 정확 시각 규칙만.
- 라벨: `자동(SMS)` / `자동(PUSH)`, 직접 입력은 그대로 `직접 입력`.
- 문자 앱 패키지: `com.samsung.android.messaging`, `com.google.android.apps.messaging`, `com.android.mms`, `com.android.messaging`. 그 밖(및 null)은 PUSH.
- 커밋은 명시 경로만, 메시지 끝 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- 받은 날 ≠ 문자 날짜(11/23 문자를 11/24에 받음) → 11/23 + 받은 시·분. Task 1 `sample_parsed`.
- 연말: `12/31` 문자를 1/1에 받음 → 작년 12/31. Task 1 `yearBoundary_lastYear`.
- 가맹점에 공백이 있는 문자 → 가맹점 전체 유지. Task 1 `merchantWithSpaces`.
- 같은 날 같은 금액 문자 두 건(받은 시각 다름) → 둘 다 등록. Task 1 `twoSmsSameDay_bothInserted`.
- 알림함에 남은 문자가 앱 시작 재검사로 등록됨. Task 1 `reparse_convertsStoredSms`.
